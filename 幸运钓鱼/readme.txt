幸运钓鱼 0.1.0  by jiru

在指定水域下竿, 上钩有动作栏预警, 收竿成功按权重抽一件奖励, 稀有渔获全服播报。
全程靠读取鱼钩数据包判定, 不占用任何聊天栏指令, 玩家照常用原版钓竿钓鱼即可。


运行条件
========
机器人必须待在钓鱼区附近。
服务端只推送机器人加载范围内的实体包, 机器人一旦离开, 整套检测会静默失效。
插件默认开启「机器人停靠」, 每 15 秒检查一次, 飘出去超过 8 格就自动 tp 回停靠点。


第一次使用(必做)
================
首次启动会生成配置文件, 此时「区域」里是一组示例坐标, 不改的话下竿不会有任何反应。

  "区域": {"角1": [x, y, z], "角2": [x, y, z]}

站在你服务器的钓鱼水域, 量出能把整片水面包进去的两个对角点填进去(顺序无所谓,
插件自己取各轴的最小/最大值)。y 轴也要包进去: 鱼钩落水后会浮在水面, 上下留一点余量。
贴着水边下竿判不进去的话, 把「判定容差(格)」调成 1, 表示各个方向各外扩一格。

配置只在插件启动时读一次, 改完配置要重载框架才生效。


战利品怎么配
============
"战利品" 是一个列表, 每件奖励这样写:

  {"名称": "§d钻石", "物品": "diamond", "数量": 1, "权重": 5, "稀有度": "史诗"}

  名称   显示给玩家看的名字, 可以带颜色代码
  数量   写整数是定值; 写 [2, 5] 则在 2~5 之间随机
  权重   相对权重, 不是百分比。某件的中奖率 = 它的权重 / 所有权重之和
         权重写 0 等于把这件从奖池里摘掉
  稀有度 对应下面「稀有度表」里的一个键

物品有三种给法, 三选一:

  "物品": "diamond"
      走 /give。绝大多数情况用这个。

  "战利品表": "loot_tables/gameplay/fishing/treasure.json"
      走 /loot give。基岩版的 /give 带不了附魔数据, 想发带真附魔的书和装备
      只有这条路。并且只判一次。

  "备用物品": "enchanted_book"
      仅在配了「战利品表」时作为兜底, 单独写没有意义。

物品 ID 写错时 /give 是静默失败的, 插件会读指令回包的 SuccessCount 确认东西真发出去了
才显示提示 —— 发不出去就什么都不显示, 同时在控制台打印是哪个 ID 无效。


稀有度表
========
每个稀有度可以配颜色、音效、要不要全服播报:

  "史诗": {"颜色": "§d", "音效": "random.levelup", "全服播报": true}

默认四档: 普通 / 稀有 / 史诗 / 传说, 后两档开了全服播报。
你可以随便增删改, 只要「战利品」里的「稀有度」值能在这张表里找到就行。


提示文案
========
「即将上钩提示」「上钩提示」「钓获提示」「跑掉提示」「全服播报」都能自己改,
留空字符串表示不发这条。后三条支持这些占位符:

  {品质}  带颜色的稀有度标签, 如 §d[史诗]
  {稀有度} 稀有度名本身
  {名称}  战利品名称
  {数量}  实际发放数量
  {玩家}  玩家名

「收竿窗口(秒)」是咬钩后多久内收竿算钓上, 默认 3 秒, 超时判为跑掉。
「提示持续(秒)」是动作栏提示挂多久, 默认 2 秒。


关于「清除原版渔获」
==================
服务端自己会在收竿瞬间生成一条原版的鱼, 不清掉的话一次收竿玩家拿两份。
默认开启, 做法是在鱼钩位置执行 kill @e[type=item,r=清除半径]。

注意: 这会把该范围内所有掉落物一起清掉, 包括玩家丢在水边的东西。
所以「清除半径(格)」默认只有 3, 不建议调大。如果你的钓鱼区旁边是玩家活动区,
可以把「清除原版渔获」关掉, 代价是玩家会同时拿到原版鱼和插件奖励。


已知限制
========
鱼钩数据包里带主人 ID 时认人是准的。少数情况下拿不到主人 ID, 会退化成
「取离鱼钩最近的在线玩家」, 两个人肩并肩下竿时有可能认错人。

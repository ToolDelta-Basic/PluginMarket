## 一、插件简介

**CyanStock** 是一款基于 ToolDelta 框架开发的 Minecraft 基岩版**券商股票模拟交易系统**插件。玩家使用服务器计分板货币（如 kp）在五家虚拟券商处买卖股票，体验完整的股市生态：行情波动、市场情绪、随机事件、VIP等级加成等机制一应俱全。

插件灵感源于一位群友的构想，由 CyanForest 从 1 独立完成全部代码编写与系统设计，并添加四大核心玩法。

### 核心特性

- **五家券商**：平安、国泰、华泰、中信、海通，风险与收益递增
- **市场情绪系统**：库存供需驱动情绪指数，影响卖出价格与风险等级
- **随机市场事件**：利好/利空事件定时触发，全局或单券商影响价格
- **VIP等级体系**：累计交易额自动升级，享受买入折扣与卖出加成
- **动态风险等级**：牛市降风险、熊市升风险，随市场情绪波动
- **全菜单交互**：聊天栏数字菜单 + 快捷文字命令双入口
- **全参数可视化配置**：ToolDelta 面板直接编辑，无需改代码

## 二、安装方法

### 前置条件

1. 已给服务器部署ToolDelta
2. 已安装 **聊天栏菜单** 插件（ToolDelta 内置插件，提供 `.help` 菜单入口）
3. 服务器已有一个计分板作为货币（如 `kp`）

### 安装步骤

1. 将 `CyanStock(券商股票系统)` 文件夹放入 ToolDelta 的插件文件目录
2. 文件夹内应包含：
   - `__init__.py` — 主程序
   - `datas.json` — 插件安装信息
3. 启动 ToolDelta，插件会自动加载并生成数据文件
4. 首次加载后，在 ToolDelta 面板的插件配置页即可可视化编辑所有参数

### 首次启动

插件启动后会自动：
- 创建计分板（如 `kp`），若已存在则跳过
- 初始化五家券商的库存股票
- 注册聊天栏菜单触发词 `.券商股票` 和 `.stock`
- 启动三个后台线程：定时补货、定时事件、自动存档

## 三、配置详解

配置文件 `CyanStock(券商股票系统).json` 位于插件配置文件夹内。所有参数均可在 ToolDelta 面板中可视化编辑，也可直接手动修改 JSON 文件。

### 基础参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `计分板名称` | 字符串 | `"kp"` | 服务器货币的计分板名称，必须与服务器实际使用的计分板一致 |
| `注册赠送货币数` | 整数 | `12000` | 新玩家注册时赠送的货币数量，用于第一笔投资 |
| `初始库存股数` | 整数 | `500` | 每家券商的初始/补货后的股票库存总量 |
| `单家持仓上限` | 整数 | `999` | 单个玩家在单家券商的最大持仓股数 |
| `单笔购入上限` | 整数 | `9999` | 单次购买的股票数量上限，防止手滑输入过大数值 |
| `会话超时秒数` | 整数 | `300` | 玩家菜单交互会话的超时时间（秒），超时后自动关闭 |
| `补货间隔分钟` | 整数 | `10` | 每 N 分钟自动补满所有券商库存，同时更新市场情绪 |
| `事件触发间隔分钟` | 整数 | `10` | 每 N 分钟尝试触发一次随机市场事件 |
| `事件持续时间分钟` | 整数 | `8` | 每个市场事件的持续时长（分钟） |
| `初始市场情绪` | 整数(0-100) | `30` | 服务器重启/首次启动时的市场情绪初始值 |
| `全局事件情绪影响` | 整数 | `5` | 全局事件触发时对市场情绪的增减幅度（利好 +delta，利空 -delta） |
| `单券商事件情绪影响` | 整数 | `2` | 单券商事件触发时对市场情绪的增减幅度（利好 +delta，利空 -delta） |
| `事件触发概率` | 整数(0-100) | `70` | 每次事件检查时的触发概率（百分比），未触发则下次 +10%（最高 95%） |

> **提示**：`初始市场情绪` 设为 30 表示冷启动（偏恐慌），50 为中性，70 为偏乐观。根据服务器风格选择。
>
> **事件情绪**：全局事件影响所有券商，情绪波动大（默认 ±5）；单券商事件仅影响一家，情绪波动小（默认 ±2）。可按需调整。

### 券商配置

每家券商有四个属性：

| 属性 | 说明 |
|------|------|
| `购买成本` | 每股买入价格（VIP有折扣） |
| `风险等级` | 可选值：`低`、`中`、`中高`、`高`、`极高`，会随市场情绪值变化而波动 |
| `最低卖出` | 每股卖出价格下限（受事件和情绪修正） |
| `最高卖出` | 每股卖出价格上限（受事件和情绪修正） |

默认配置：

| 券商 | 购买成本 | 风险等级 | 最低卖出 | 最高卖出 |
|------|----------|----------|----------|----------|
| 平安证券 | 1500 | 低 | 800 | 2500 |
| 国泰证券 | 3500 | 中 | 1500 | 6500 |
| 华泰证券 | 7000 | 中高 | 3000 | 14000 |
| 中信证券 | 15000 | 高 | 6000 | 30000 |
| 海通证券 | 35000 | 极高 | 12000 | 70000 |

> **设计思路**：低价券商适合新手练手，高价券商适合大户博弈。卖出价为区间随机，低买高卖赚取差价。

### 会员等级配置

玩家通过累计交易额自动升级，享受买入折扣和卖出加成。

| 属性 | 说明 |
|------|------|
| `等级名称` | 显示名称 |
| `累计交易额` | 达到该交易额即可升至本等级 |
| `购买折扣` | 买入时的折扣比例（0.03 = 降价3%） |
| `卖出加成` | 卖出时的额外收益比例（0.02 = 加价2%） |
| `显示颜色` | Minecraft 颜色代码（如 `§e` 金色） |

默认等级：

| 等级 | 累计交易额 | 买入折扣 | 卖出加成 | 颜色 |
|------|------------|----------|----------|------|
| 普通 | 0 | 0% | 0% | §7 灰 |
| 铜牌 | 50000 | 3% | 2% | §6 金 |
| 银牌 | 200000 | 5% | 3% | §f 白 |
| 金牌 | 800000 | 8% | 5% | §e 黄 |
| 钻石 | 2500000 | 12% | 8% | §b 青 |

> **交易额** = 买入花费 + 卖出收入，双向累计。

### 市场事件配置

事件每 `事件触发间隔分钟` 尝试触发一次（默认 70% 概率成功，可通过 `事件触发概率` 配置；失败后概率递增 +10%，最高 95%）。

| 属性 | 说明 |
|------|------|
| `事件类型` | `利好`（涨价）或 `利空`（跌价） |
| `影响范围` | `全局`（所有券商）或 `单券商`（随机一家） |
| `事件描述` | 显示给玩家的事件说明文字 |
| `持续时间分钟` | 事件生效时长 |
| `价格修正` | 价格乘数（1.10 = 涨10%，0.90 = 跌10%） |

默认事件修正幅度：

| 类型 | 范围 | 修正 |
|------|------|------|
| 利好 | 全局 | ×1.10 |
| 利空 | 全局 | ×0.90 |
| 利好 | 单券商 | ×1.15 |
| 利空 | 单券商 | ×0.85 |

> **提示**：修正幅度越大，市场波动越剧烈。新手服建议保持默认（±10%~15%），追求刺激可调高。

## 四、玩法说明

### 4.1 玩家入门流程

1. **注册账户**：在聊天栏输入 `.券商股票` 打开主菜单，选择 `1 注册`，系统赠送初始货币
2. **查看行情**：选择 `7 走势` 查看所有券商的库存、成本、风险和当前卖出价
3. **买入股票**：选择 `3 买入` → 选券商 → 输入数量，自动扣除货币
4. **等待时机**：关注市场情绪和事件，在价格高时卖出
5. **卖出股票**：选择 `4 卖出` → 选券商 → 输入数量，或选 `5 清仓` 一键卖出全部
6. **查看持仓**：选择 `6 持仓` 查看当前持有股票和预估收益

### 4.2 菜单操作

在聊天栏输入 `.券商股票` 即可打开主菜单。菜单分页显示（每页5项），操作方式：

| 操作 | 说明 |
|------|------|
| 输入数字 | 选择对应菜单项 |
| `+` | 下一页 |
| `-` | 上一页 |
| `r` | 返回主菜单（仅在子面板中有效） |
| `q` 或 `0` | 退出交易系统 |

### 4.3 快捷文字命令

### 4.4 交易机制详解

#### 买入流程

1. 选择券商后，系统显示该券商详情（成本、风险、收益区间、库存、你的持仓）
2. 输入购买数量（不能超过 `单笔购入上限`）
3. 系统计算总成本 = 单价 × 数量 × (1 - VIP折扣)
4. 扣除货币，增加持仓，减少券商库存
5. 若持仓触及上限，首次仅警告"再次购买将强制平仓"，第二次购买才会自动清仓

#### 卖出流程

1. 选择券商后，显示当前持有数量
2. 输入卖出数量
3. 系统计算收益 = 每股随机(最低卖出~最高卖出) × 数量 × (1 + VIP加成)
4. 卖出价受当前市场情绪和活跃事件修正
5. 增加货币，减少持仓

#### 一键清仓

- 选择券商后，系统会要求输入 `y` 确认操作
- 确认后一次性卖出该券商全部持仓

## 五、核心机制

### 5.1 市场情绪

市场情绪是一个 0-100 的指数，代表市场整体信心：

| 指数范围 | 状态 | 颜色 |
|----------|------|------|
| 0-19 | 极度恐慌 | §4 暗红 |
| 20-34 | 恐慌 | §c 红 |
| 35-44 | 谨慎 | §6 橙 |
| 45-55 | 中性 | §e 黄 |
| 56-70 | 乐观 | §a 绿 |
| 71-85 | 狂热 | §2 深绿 |
| 86-100 | 极度狂热 | §d 粉 |

**情绪如何变化**：
- 补货时：根据库存消耗率更新（买的人多 → 库存低 → 情绪高）
- 事件触发：利好 +delta，利空 -delta
  - 全局事件 delta = `全局事件情绪影响`（默认 5）
  - 单券商事件 delta = `单券商事件情绪影响`（默认 2）
- 情绪影响卖出价：每偏离1点，价格修正 ±1%（0.01）

### 5.2 随机事件

事件每隔 `事件触发间隔分钟` 尝试触发一次：
- **默认 70% 概率**触发成功（可通过 `事件触发概率` 配置），触发后概率重置为初始值
- **未触发时**，下次概率 +10%（最高 95%），确保不会太久没事件

事件触发后：
- 全局事件影响所有券商的卖出价
- 单券商事件仅影响一家（随机选择）
- 多个事件可叠加（价格修正相乘）
- 事件到期后自动失效

### 5.3 动态风险等级

风险等级不是固定的，会随市场情绪波动：

- **市场情绪 ≤ 30**（恐慌）：风险等级升一级（如"中" → "中高"）
- **市场情绪 ≥ 70**（乐观）：风险等级降一级（如"高" → "中高"）
- 其他区间：显示原始风险等级

> 这意味着熊市中所有券商风险更高，牛市中风险更低，模拟真实市场心理。

### 5.4 价格修正公式

最终卖出价 = 基准卖出价 × 事件修正系数 × 情绪修正系数

- **事件修正系数**：所有活跃事件的价格修正值相乘
- **情绪修正系数**：1.0 + (情绪指数 - 50) / 100
- 最终结果限制在 0.3 ~ 3.0 之间

**举例**：
- 基准卖出价：1000
- 活跃事件：全局利好 ×1.10，单券商利好 ×1.15
- 市场情绪：70
- 最终修正 = 1.10 × 1.15 × (1.0 + 20/100) = 1.10 × 1.15 × 1.20 = 1.518
- 实际卖出价区间 = 1000~2500 × 1.518 ≈ 1518~3795

### 5.5 VIP等级

- 交易额 = 买入花费 + 卖出收入，双向累计
- 达到门槛自动升级，并发送升级提示
- 买入折扣：降低购买成本
- 卖出加成：提高卖出收益
- 等级越高，差价利润越大

插件运行后会在 插件数据 目录下生成：

## 七、服主调优指南

### 7.1 经济平衡原则

配置数值时，参考服务器实际经济水平：

1. **注册赠送**：设为玩家能买 1-3 手低价券商股票的金额
2. **券商成本**：低价券商 = 日常零花钱级别，高价券商 = 需要努力攒钱
3. **卖出区间**：最低卖出应低于买入成本（可能亏本），最高卖出应高于成本（盈利）
4. **VIP门槛**：第一级应该是普通玩家 1-2 天能达到的水平，满级需要长期活跃

### 7.2 常见调整场景

**想让市场更刺激**：
- 提高事件修正幅度（如利好 1.25、利空 0.75）
- 缩短事件间隔（如 5 分钟）
- 降低初始情绪（如 20）

**想让市场更平稳**：
- 降低事件修正幅度（如利好 1.05、利空 0.95）
- 延长事件间隔（如 20 分钟）
- 提高初始情绪（如 60）

**防止垄断**：
- 降低 `单家持仓上限`（如 50）
- 降低 `初始库存股数`（如 100）

**鼓励交易**：
- 提高 `注册赠送货币数`
- 降低 VIP 第一级门槛
- 缩短补货间隔

### 7.3 重置数据

如需清空所有玩家数据重新开始：
1. 停止服务器
2. 删除 `stock_data.json`
3. 重启服务器

## 九、常见问题

**Q: 玩家提示"请先注册"怎么办？**  
A: 让玩家先输入 `.券商股票` 打开菜单，选择 1 注册。注册后系统赠送初始货币。

**Q: 券商库存为0买不了怎么办？**  
A: 库存会定时自动补货（默认10分钟）。玩家也可以查看 `.走势` 了解当前库存情况，等待补货。

**Q: 卖出价和基准价不一样？**  
A: 卖出价受市场情绪和活跃事件影响，会动态浮动。查看 `.情绪` 了解当前修正情况，↑ 表示涨价、↓ 表示跌价。

**Q: 修改配置后不生效？**  
A: 修改配置后需要重启 ToolDelta。如果修改了券商价格或VIP门槛，建议同时删除 `stock_data.json` 重置数据。

**Q: 旧命令还能用吗？**  
A: 可以。`.买入` `.购买` `.卖出` `.一键卖出` `.行情` `.股势` `.详情` `.公司详情` `.特权` `.会员` `.列表` `.说明` `.指南` 等旧命令仍然有效，会静默转发到对应新命令。

**Q: 为什么看到"持仓预警"但没有被平仓？**  
A: 触及持仓上限后，首次仅警告不会平仓。再次购买同一券商才会触发强制清仓，给玩家缓冲时间。

**Q: 怎么自定义券商名称？**  
A: 在配置文件的 `券商配置` 中修改 key 名称即可。但注意修改后需重置数据，否则旧数据中的券商名不匹配。

**Q: 计分板名称怎么改？**  
A: 修改配置中的 `计分板名称` 为你服务器实际使用的计分板。插件会自动创建该计分板（若不存在）。

## 十、技术信息

### 线程模型

插件运行三个 daemon 线程：

| 线程 | 功能 | 间隔 |
|------|------|------|
| 补货线程 | 补满库存 + 更新情绪 + 清理过期事件 | 配置项 `补货间隔分钟` |
| 事件线程 | 尝试触发随机事件 + 更新情绪 | 配置项 `事件触发间隔分钟` |
| 存档线程 | 自动保存数据 + 清理超时会话 | 30秒 |

### 数据安全

- `_data_lock` 保护玩家数据、券商库存、活跃事件的读写，防止交易/补货/事件三线程并发冲突
- `_save_lock` 独立保护存档写入
- **原子写入**：先写 `.tmp` 临时文件，再 `replace()` 到目标文件，崩溃不损坏 JSON
- 市场情绪和券情展示时均锁内快照，确保读取一致性
- 会话使用 `RLock` 支持嵌套加锁
- 插件退出时停止后台线程并强制 flush 保存

### 依赖

- ToolDelta 框架
- 聊天栏菜单插件（可选，不影响核心功能，仅缺少 `.help` 入口）

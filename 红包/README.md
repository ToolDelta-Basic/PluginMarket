# 红包

ToolDelta 类式插件。玩家可以使用经济计分板发送拼手气口令红包。

## 使用

```text
.fhb <总金额> <份数> <口令>
.发红包 <总金额> <份数> <口令>
```

缺少参数时，插件会在聊天栏逐项询问。输入 `取消` 或 `q` 可以退出。

- 红包会向全服展示发送者、总金额和领取口令。
- 领取成功消息始终全服播报。
- 红包被抢完后会全服播报领取金额最高的玩家。
- 每名玩家在同一个红包中只能领取一次，发送者也可以领取。
- 红包 10 分钟未领完时，剩余金额自动退回；重启 ToolDelta 不会重置计时。
- `�`、控制符、不可见格式符等无效字符不能用于口令；尝试使用时会收到禁止提示。

## 配置

首次加载后会生成 `插件配置文件/红包.json`：

```json
{
  "经济计分板": "money",
  "货币名称": "星尘",
  "红包有效期秒数": 600
}
```

需要安装 `聊天栏菜单` 0.4.1 或更高版本。
